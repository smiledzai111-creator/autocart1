CART BOMB - Fabric mod cho Minecraft Java 1.21.11 (can Java 21 + Fabric API)

CACH BUILD RA FILE .JAR:
1. Cai Java 21 (JDK).
2. Cai Gradle (https://gradle.org/install) roi mo terminal trong thu muc nay chay:
      gradle wrapper
      gradlew build        (Windows)   |   ./gradlew build   (Mac/Linux)
   Hoac mo thu muc nay bang IntelliJ IDEA, doi Gradle import xong, chay task "build".
3. File mod nam o: build/libs/cartbomb-1.0.0.jar  (KHONG lay file -sources.jar)
4. Bo file jar vao thu muc mods cung Fabric Loader + Fabric API 1.21.11.

CACH DUNG:
- Hotbar: Cung (enchant Flame), Duong ray, TNT Minecart; trong tui co mui ten.
- Nhin vao 1 block, nhan K. Doi phim trong Options > Controls.
- Chi TNT Minecart moi no (bi mui ten lua ban trung).
